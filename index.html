How it works

A controlled bridge, not a second CRM.

The MCP server translates approved AI requests into read operations against Dynamics 365. Data is retrieved when needed; this public site contains no server code or connection details.

1 · Ask

Safety boundary

Useful access starts with a narrow scope.

Production access should match a defined use case and the least CRM permissions needed for it. Availability and supported record types are confirmed for each environment.

Read-oriented from the start

The current MCP tool surface exposes retrieval and metadata operations, not record creation, updates or deletion.
Dynamics credentials remain in the private server environment and are not published on this site.
Queries can be bounded and field-selected to reduce unnecessary data retrieval.
The configured Dynamics service identity and CRM permissions remain the authorization boundary.

Private implementation

Codicent Dynamics CRM MCP is a private server. This repository and website publish only product information — not implementation, deployment configuration or customer access details.
