# Codicent Dynamics CRM MCP

Public product site for the private Codicent Dynamics CRM MCP server.

**Website:** https://dynamics.codicent.ai/

## About this repository

This public repository contains only the static marketing and product-documentation
site. The MCP server implementation, deployment configuration, endpoints,
credentials, tenant data and customer data are private and are not distributed here.

The canonical site source lives in the private `izaxon/codicent-core` repository
and is synced here automatically. Direct changes to this repository will be
overwritten by the next sync.

For access, contact [johan@codicent.com](mailto:johan@codicent.com).
